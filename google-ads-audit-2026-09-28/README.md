# Аудит Google Ads — Sterling Home Group (аккаунт «Maks – Kvoka Studio»)

Период: 21–27 сентября 2026 (полная неделя) + 28 сентября 2026 (до ~13:00 по времени аккаунта).

## С чего начать

1. `Sterling_Ads_Audit_2026-09-28.xlsx` — все 10 таблиц одной книгой Excel (лист «Читать сначала» + 10 листов). Открывается в любом Excel и Google Таблицах, числа — числами, цветом выделены P0 / P1 / «решение».
2. `audit.html` — интерактивный отчёт (HTML + CSS + JS в одном файле, работает офлайн: открыть двойным кликом).
3. `import/` — готовые файлы для Google Ads Editor (Аккаунт → Импорт → Из файла), только колонки Editor, порядок в `import/README.txt`.

## CSV (те же таблицы, что в Excel-книге)

- `csv/01_минус_слова_добавить.csv` — минус-слова по кампаниям (колонки Google Ads Editor: Campaign / Keyword / Criterion Type + приоритет и причина). Только новые: дубли с уже стоящими минус-словами убраны. Приоритет «решение» и «P2 (решение)» — по вашему усмотрению.
- `csv/02_ключевые_слова_добавить_точные.csv` — точные ключи из конвертирующих запросов + brand-кампания.
- `csv/03_ключевые_слова_пауза_или_изменить.csv` — ключи и группы на паузу / перевод в точное соответствие; отдельно помечены уже удалённые вами ключи (справочно).
- `csv/04_кампании_бюджеты_и_ставки.csv` — бюджеты (по вашему решению не снижаем), стратегии, лимиты ставок, план по tCPA, действия по каждой кампании.
- `csv/05_объявления_правки.csv` — 28 Poor RSA, гео-ошибки, закрепления, заявления, расширения, сайтлинки уровня аккаунта.
- `csv/06_целевые_страницы.csv` — 88 сайтлинков FL → /chicago/, сайтлинки уровня аккаунта → /destin/, страницы с кликами и конверсиями, домены, скорость, трекинг.
- `csv/07_план_действий_полный.csv` — задачи P0–P3 (бюджеты не трогаем; вместо этого правило-уведомление о всплеске расхода).
- `csv/08_конфликты_минус_слов_и_ключей.csv` — конфликты «минус-слово блокирует свой же ключ» только в активных группах (пары в группах Sub-Zero, которые вы поставили на паузу в MIAMI/TAMPA, исключены).
- `csv/09_поисковые_запросы_21-28.09_с_вердиктом.csv` — 578 строк запросов с вердиктом.
- `csv/10_клики_выше_лимита_ставки.csv` — доказательная таблица по дорогим кликам.

Кодировка CSV — UTF-8 с BOM, разделитель запятая. В русском Excel такой CSV открывается через Данные → Из текста/CSV (или используйте xlsx-книгу).

Отчёты Google Ads (кампании, группы, ключи, запросы, посадочные, устройства, аукционы, пакетные стратегии, местоположения, карточки «Обзор») за оба периода и экспорт Google Ads Editor от 28.09.2026 (22 кампании, 330 групп, 660 RSA, 15 187 ключей, 5 201 минус-слово, 1 304 локации).
