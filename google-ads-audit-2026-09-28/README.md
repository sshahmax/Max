# Аудит Google Ads — Sterling Home Group (аккаунт «Maks – Kvoka Studio»)

Период: 21–27 сентября 2026 (полная неделя) + 28 сентября 2026 (до ~13:00 по времени аккаунта).

## Файлы

- `audit.html` — интерактивный отчёт (HTML + CSS + JS в одном файле, работает офлайн: открыть двойным кликом). Разделы: итог, клики выше лимита ставки, хронология 7 дней + сегодня, кампании, структура, группы, поисковые запросы, ключи, объявления, посадочные, ставки и конверсии, устройства/аудитория/конкуренты, плюсы и минусы, план действий с галочками, список CSV, метод.
- `csv/01_минус_слова_добавить.csv` — минус-слова по кампаниям (колонки Google Ads Editor: Campaign / Keyword / Criterion Type + приоритет и причина).
- `csv/02_ключевые_слова_добавить_точные.csv` — точные ключи из конвертирующих запросов + brand-кампания.
- `csv/03_ключевые_слова_пауза_или_изменить.csv` — ключи и группы на паузу / перевод в точное соответствие.
- `csv/04_кампании_бюджеты_и_ставки.csv` — бюджеты сейчас/рекомендуемые, стратегии, лимиты ставок, план по tCPA, действия по каждой кампании.
- `csv/05_объявления_правки.csv` — 28 Poor RSA, гео-ошибки, закрепления, заявления, расширения.
- `csv/06_целевые_страницы.csv` — 88 сайтлинков FL → /chicago/, страницы с кликами и конверсиями, домены, скорость, трекинг.
- `csv/07_план_действий_полный.csv` — 30 задач P0–P3.
- `csv/08_конфликты_минус_слов_и_ключей.csv` — 302 конфликта.
- `csv/09_поисковые_запросы_21-28.09_с_вердиктом.csv` — 578 строк запросов с вердиктом.
- `csv/10_клики_выше_лимита_ставки.csv` — доказательная таблица по дорогим кликам.

Кодировка CSV — UTF-8 с BOM, разделитель запятая (Excel, Google Таблицы, Google Ads Editor).

## Источники

Отчёты Google Ads (кампании, группы, ключи, запросы, посадочные, устройства, аукционы, пакетные стратегии, местоположения, карточки «Обзор») за оба периода и экспорт Google Ads Editor от 28.09.2026 (22 кампании, 330 групп, 660 RSA, 15 187 ключей, 5 201 минус-слово, 1 304 локации).
