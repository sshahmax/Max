Как импортировать в Google Ads Editor
1. Editor → Аккаунт → Импорт → Из файла (или вставить из буфера). Выбрать файл.
2. Editor покажет предпросмотр: столбцы уже названы как в Editor (Campaign, Ad Group, Keyword, Criterion Type, Final URL, Status).
3. Проверить, что ошибок нет, нажать «Завершить», затем «Опубликовать».

Порядок:
  1. 03_pauza_editor.csv              — сначала: поставить на паузу фразовые ключи из CSV 03 (иначе точный минус «appliance repair santa rosa beach» в DESTIN конфликтует с активным ключом группы 17).
  2. 01_minus_slova_editor.csv        — минус-слова P0 и P1 во все кампании (строки P2, «P2 (решение)» и «решение» из CSV 01 сюда не входят — они за вами).
  3. 03_dobavit_tochnye_editor.csv    — добавить точные версии вместо фразовых (только те, которых в группе ещё нет).
  4. 02_klyuchi_editor.csv            — новые точные ключи из запросов с конверсиями (без brand-кампании и её 5 ключей — их создать вручную по CSV 02; без строк «РЕШЕНИЕ»).

Ключ [sub zero authorized repair] (CSV 02) в файл 02 не включён: в CHICAGO Lux он заработает только после удаления минусов «authorized» (широкий) и «authorized repair» (фразовый) — см. CSV 08. После их снятия добавить вручную.
