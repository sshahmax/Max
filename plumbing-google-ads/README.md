# Plumbing & Drain — Google Ads Blueprint

Стратегия Google Ads для plumbing/drain-компании на 5 локаций, построенная на пяти выгрузках
Google Keyword Planner (699 ключей × 5 локаций, сентябрь 2025 – август 2026).

## Файлы

| Файл | Что внутри |
|---|---|
| `plumbing-ads-blueprint.html` | Полный документ стратегии: анализ данных, принципы, неделя 0, сайт и посадочные, структура аккаунта, объявления, негативы, ставки и бюджет, прогноз, 90-дневный план, команда и риски |
| `keyword_map.csv` | Все 699 ключей с действием (TARGET / TEST / COMPETITOR / SKIP / NEGATIVE), кампанией, группой объявлений, типом соответствия, объёмом по каждой локации и ставками top-of-page |
| `campaign_structure.csv` | 19 кампаний: тип, гео, месяц запуска, стратегия ставок, стартовый tCPA, потолок CPC, доля бюджета, расписание, посадочная, конверсии |
| `negative_keywords_master.csv` | Общие списки минус-слов по темам (220 терминов) для загрузки как shared negative lists |

## Итог карты ключей

| Действие | Ключей | Запросов/мес |
|---|---:|---:|
| TARGET (в работу, месяц 1) | 402 | 75 560 |
| TEST (тест со 2-го месяца, DIY/товарный риск) | 40 | 18 760 |
| COMPETITOR (кампания по конкурентам) | 31 | 2 680 |

Локации в выгрузках не названы, поэтому в файлах они обозначены Geo1–Geo5 (Geo1 — самая крупная, ~51% спроса).
